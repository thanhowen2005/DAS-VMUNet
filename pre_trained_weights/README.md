# Pretrained encoder weights

Place `vmamba_small_e238_ema.pth` in this directory. Both dataset configurations load the encoder checkpoint from `./pre_trained_weights/vmamba_small_e238_ema.pth` when training is launched from the DAS-VMUNet repository root.

You could download the weights used by VM-UNet from [Baidu Drive](https://pan.baidu.com/s/1ci_YvPPEiUT2bIIK5x8Igw?pwd=wnyy) or [Google Drive](https://drive.google.com/drive/folders/1Fr7zM1wq7106d0P7_3oeU5UZqUvk2KaP?usp=sharing)
